# sdc-inventory-tracker
SDC's Design Team Inventory Tracking Tool

## Setup

This repo is a [pnpm](https://pnpm.io) workspace (`backend`, `frontend`, `shared`). Install pnpm, then from the repo root:

```sh
pnpm install
pnpm dev
```
